# Repository Working Rules

All coding agents working in this repository must follow `CONTRIBUTING.md`.

- Never implement changes directly on `main` or `develop`.
- Use one dedicated branch per feature, bug, refactor, documentation update, or GitHub Issue.
- Branch names and commit messages must be lowercase English without accents.
- Use the branch prefixes `feature/`, `fix/`, `refactor/`, and `docs/`.
- Use the commit prefixes `feat:`, `fix:`, `refactor:`, and `docs:`.
- Keep each change focused and verify it before proposing a commit.
