# Crypto Portfolio API

Express API organized by feature modules, following the route/controller/service pattern used by the Bot Farm backend.

## Commands

```bash
npm run dev
npm test
npm run lint
npm run format
```

## Initial endpoints

- `GET /api/v1/health`
- `GET /api/v1/portfolio/capabilities`
- `GET /api/v1/import/requirements`

Portfolio calculation and CSV upload will be implemented inside their existing feature modules.
